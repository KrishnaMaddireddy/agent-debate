# Agent Debate

Multiple models, one prompt, a real argument, measured in code.
Generalised from Model Bridge — any topic, no MCP required.

- `PRD.md` — the product requirements (read first)
- `CLAUDE.md` — how Claude Code should work in this repo
- `providers.json.example` — model config template (rename to `providers.json`;
  keys stay in `.env`)
- `personas/`, `skills/` — judging lenses and house procedures (empty at start)
